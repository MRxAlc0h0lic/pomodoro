# 🍅 Pomodoro Timer

A clean, lightweight Pomodoro timer built with vanilla HTML/CSS/JavaScript — no frameworks, no build step, just open `index.html` and go.

## ✨ Features

- ⏱️ **Classic Pomodoro workflow** — work sessions, short breaks, and long breaks
- 🔔 **Audio alerts** powered by the Web Audio API — no external sound files needed
- 📊 **Per-session tracking** — keeps count of completed focus sessions toward your target
- 🔒 **Sanitized input handling** — user inputs are cleaned to prevent XSS
- 🎨 **Single-file, dependency-free** — everything runs client-side in one `index.html`

## 🚀 Getting Started

No installation required.

```bash
git clone https://github.com/MRxAlc0h0lic/pomodoro.git
cd pomodoro
```

Then just open `index.html` in your browser — or serve it locally:

```bash
python3 -m http.server 8000
```

and visit `http://localhost:8000`.

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (Web Audio API)
